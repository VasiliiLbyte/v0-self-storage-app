description: Старт сессии — сводка состояния проекта из hub/

Начало сессии. Код не пиши.

1. Прочитай `hub/PROJECT.md` целиком.
2. В `hub/PROGRESS.md` прочитай только разделы «Активно», «Следующее», «Блокеры и открытые
   вопросы», «Отложено / HOLD», «Ожидает деплоя» (строки не в статусе `deployed`)
   и 5 верхних строк «Лог сессий». Весь журнал не грузи.
3. Посмотри последние файлы задач (`ls -t hub/tasks | head -10`) и прочитай те, что относятся
   к активным задачам. Ищи задачи без отчёта о проверке.
4. Выполни `git status`, `git branch --show-current`, `git fetch origin` и сравни с `origin/main`:
   ветка, отставание, незакоммиченные файлы. Ничего не меняй.
5. Если есть строки «Ожидает деплоя» и доступен `gh`, сверь статус деплоя их SHA
   (`hub/DEPLOY.md` §5).

Выдай сводку одним экраном:
- **В работе:** активные задачи и их статус
- **Ждёт решения оператора:** approve планов, вопросы, HOLD, блокеры
- **Ждёт деплоя:** DEP-NNN, SHA, миграции
- **Расхождения:** грязная рабочая копия, ветка отстала, журнал не совпадает с git или Vercel
- **Предлагаю следующим:** 1–3 пункта с обоснованием
