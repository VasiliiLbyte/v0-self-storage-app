Закрытие сессии.

1. Обнови `hub/PROGRESS.md`:
   - «Последнее обновление» в шапке
   - «Активно», «Следующее», «Блокеры», «Отложено» по факту
   - «Ожидает деплоя»: у каждой проверенной задачи есть строка, статусы соответствуют evidence
   - лог сессий: строки за сегодня с ID и результатами проверок (сверху)
2. Долгоживущие решения запиши в `hub/DECISIONS.md` (номер: `bash hub/scripts/next-id.sh D`).
3. Изменения API отрази в `hub/API_CONTRACT.md`, инфраструктуры — в `hub/DEPLOY.md` §8,
   новые уроки — в `hub/playbook/LESSONS.md`.
4. Если `hub/PROGRESS.md` больше ~1500 строк, предложи оператору ротацию в `hub/archive/`.
5. Выполни `git status`. Предложи оператору коммит **только** файлов этой сессии (явные пути,
   сообщение через HEREDOC). Чужие незакоммиченные правки не трогай, перечисли их.
   Коммит — после «go». Push в `main` — только оператор: это деплой.

Итог оператору в 3–5 строк: что закрыто, что ждёт деплоя, что следующее. $ARGUMENTS
