# Pelikan Storage: вход для агента

Сайт аренды складских ячеек «Пеликан» (Мытнинская наб., 5/7, Санкт-Петербург):
лендинг, бронирование с договором и оплатой ЮKassa, личный кабинет, админка.
Next.js 16 + Supabase, деплой на Vercel.

Правила работы взяты из Control Hub Kit и адаптированы под один репозиторий: память проекта
лежит здесь же, в [`hub/`](hub/README.md). Код пишет агент (Claude Code), прод трогает
только оператор.

## Порядок чтения (не грузить весь репозиторий)

1. [`hub/PROJECT.md`](hub/PROJECT.md): окружения, стек, команды проверки, источники правды
2. [`hub/PROGRESS.md`](hub/PROGRESS.md): разделы «Активно», «Следующее», «Блокеры», «Ожидает деплоя»
3. [`hub/playbook/PIPELINE.md`](hub/playbook/PIPELINE.md): цикл задачи, ID, статусы
4. [`hub/DECISIONS.md`](hub/DECISIONS.md): только при правках логики или архитектуры
5. [`hub/API_CONTRACT.md`](hub/API_CONTRACT.md), [`hub/DEPLOY.md`](hub/DEPLOY.md): если задача их касается
6. Файл текущей задачи в `hub/tasks/`

## Общие запреты

- Не помечать работу выполненной без собственной проверки по [`hub/playbook/VERIFY.md`](hub/playbook/VERIFY.md).
- **Push и merge в `main` = деплой в прод** (Vercel собирает `main` автоматически).
  Только после явного «go» оператора.
- Не ставить `deployed` без evidence: SHA в Vercel-деплое со статусом Ready, прод отвечает 200, смоук.
- Не применять SQL к Supabase, не менять env на Vercel, настройки ЮKassa, DNS и аккаунты.
  Агент готовит SQL и команды, оператор выполняет.
- Не вводить и не показывать пароли, ключи и токены. `.env*` не читать целиком и не править
  без явного пункта в задаче.
- Цены, суммы и статусы оплаты считаются только на сервере. Клиенту не доверять.
- Не коммитить чужие незакоммиченные правки. Перед коммитом смотреть `git status`,
  добавлять файлы по конкретным путям.
- Не делать `git reset --hard`, `push --force`, `clean -fd`.
- Не переписывать историю в `hub/DECISIONS.md`: только дописывать, старое помечать `Superseded`.
- Пути с пробелами всегда в кавычках: корень проекта лежит в `/Users/vasilii/Desktop/code /`.
