# hub/evidence/

Доказательства к отчётам и решениям: выводы проверок, скриншоты смоука, выборки из БД.

- Имя файла: `<ID задачи>-<что>-<YYYYMMDD>.<ext>`, например `SEC-BOOKING-PRICE-smoke-20261030.png`
- В отчёте нужна ссылка на файл, а не пересказ
- Персональные данные клиентов (ФИО, телефоны, паспорта, email) и секреты сюда не кладутся.
  Если без них никак, файл уходит в `hub/evidence/private/` (он в `.gitignore`)
