# hub/: память проекта

Правила работы с ИИ-агентом по мотивам Control Hub Kit, адаптированные под один репозиторий
и одного агента (D-001). Вход для агента: [`../AGENTS.md`](../AGENTS.md) и [`../CLAUDE.md`](../CLAUDE.md).

```
hub/
  PROJECT.md            рамка: окружения, стек, команды проверки, источники правды
  PROGRESS.md           живой журнал: активно / дальше / блокеры / ожидает деплоя / лог
  DECISIONS.md          журнал решений (только дописывать)
  API_CONTRACT.md       контракт route handlers и прямых запросов к Supabase
  DEPLOY.md             раннбук: Vercel, миграции Supabase, откат
  playbook/
    PIPELINE.md         роли, размер задачи, цикл, ID, статусы, сессии
    VERIFY.md           протокол самопроверки (5 слоёв, обязательные регрессии)
    LESSONS.md          уроки, в том числе собственные инциденты проекта
  templates/
    TASK.md             план задачи + отчёт о проверке в одном файле
    DEPLOY_BLOCK.md     блок команд деплоя для оператора
    INCIDENT.md         разбор инцидента
  tasks/                файлы задач: <дата>-<ID>.task.md, <дата>-<ID>.incident.md
  evidence/             выводы проверок, скриншоты смоука (без персональных данных)
  archive/              ротация PROGRESS.md
  scripts/
    new-task.sh         создать файл задачи или инцидента из шаблона
    next-id.sh          следующий свободный DEP- / D- / INC-номер
```

Слэш-команды Claude Code лежат в `../.claude/commands/`: `/session-start`, `/task`, `/verify`,
`/deployed`, `/session-end`. Правила для Cursor — в `../.cursor/rules/`.

Секреты, значения env и персональные данные клиентов в `hub/` не пишутся: папка лежит
в репозитории вместе с кодом.
