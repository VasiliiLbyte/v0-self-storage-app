# hub/tasks/

Одна задача — один файл с планом, решениями оператора и отчётом о проверке. Имена начинаются
с даты, поэтому `ls` показывает их в хронологическом порядке.

| Файл | Шаблон |
|---|---|
| `YYYY-MM-DD-<ID>.task.md` | `hub/templates/TASK.md` |
| `YYYY-MM-DD-INC-<суть>.incident.md` | `hub/templates/INCIDENT.md` |
| `YYYY-MM-DD-<ID>.audit.md` | свободная форма: аудит или обзор, из которого рождаются задачи |

Создание: `bash hub/scripts/new-task.sh <task|incident> <ID>`.

Файлы задач не переписываются задним числом. Если план изменился после approve, ниже
дописывается раздел «Изменение плана (дата)» с решением оператора.
